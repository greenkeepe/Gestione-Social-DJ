# Dati dell'SEO Engine — generati automaticamente

I file JSON in questa cartella (`gsc-data.json`, `opportunities.json`,
`internal-links.json`) sono generati dagli script in `scripts/seo/` ed
eseguiti settimanalmente da `.github/workflows/seo-gsc.yml`.

**Non modificarli a mano**: verrebbero sovrascritti alla prossima esecuzione.
Per rigenerarli manualmente: `npm run seo:all` (vedi `site/docs/seo-engine.md`).
